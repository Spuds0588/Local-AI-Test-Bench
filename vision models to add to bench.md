Here is a summary table of the in-browser vision-language models compatible with Transformers.js (and text-side reasoning engines like WebLLM), including their loading URLs and browser setup requirements:
| Model Name | Runtime Framework | Model Hub / Loading URL | Setup & Browser Requirements |
|---|---|---|---|
| Moondream2 | Transformers.js | Xenova/moondream2 | • Package: @huggingface/transformers
• Backend: device: 'webgpu'
• Memory: ~1.8B params (~1–2 GB VRAM/RAM)
• Task: image-to-text pipeline |
| SmolVLM-Instruct | Transformers.js | HuggingFaceTB/SmolVLM-Instruct | • Package: @huggingface/transformers (v3+)
• Backend: WebGPU acceleration
• Memory: ~2B params (~2 GB footprint)
• Architecture: Uses Web Workers recommended to keep UI responsive |
| Phi-3.5 Vision | Transformers.js / Web Runtime | Xenova/Phi-3.5-vision-instruct (or ONNX Hub equivalents) | • Backend: WebGPU
• Memory: High (~4GB+ VRAM required)
• Note: Heavy resource footprint; best reserved for powerful desktop browsers |
| Llama-3.2 / Phi-3.5 (Text Agent) (Downstream) | WebLLM | Llama-3.2-1B-Instruct-q4f16_1 (via WebLLM prebuilt config) | • Package: @mlc-ai/web-llm
• Backend: WebGPU accelerated chat engine
• Role: Ingests the text description generated by the vision model above for secondary reasoning |
Quick Implementation Setup Blueprint
To wire this up in a client-side web application (such as Next.js, Vite, or a static HTML/JS app), use the following structure:
 * Install Dependencies:
   npm install @huggingface/transformers @mlc-ai/web-llm

 * Initialize the Vision Translator (Transformers.js):
   import { pipeline } from '@huggingface/transformers';

// Load Moondream2 or SmolVLM client-side using WebGPU
const visionAnalyzer = await pipeline('image-to-text', 'Xenova/moondream2', {
    device: 'webgpu'
});

// Process image and extract description text
const result = await visionAnalyzer(imageElement, {
    prompt: "Describe this image concisely for another AI assistant."
});

const textContext = result[0].generated_text;

 * Pass Text Context to the Downstream SLM (WebLLM):
   import * as webllm from "@mlc-ai/web-llm";

const engine = await webllm.CreateMLCEngine("Llama-3.2-1B-Instruct-q4f16_1");

const reply = await engine.chat.completions.create({
    messages: [
        { role: "system", content: "You are a helpful assistant analyzing visual data descriptions." },
        { role: "user", content: `Here is the visual context from the image: ${textContext}. What should we do next?` }
    ]
});
